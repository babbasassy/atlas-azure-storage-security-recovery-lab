# Evidence provenance

Live observations were captured from the Azure portal's rendered accessibility text and screenshots on 15–16 October 2026. The account JSON was copied from the portal's Resource JSON view. Raw material remains private because it includes subscription/tenant identifiers, the signed-in account and the client's public IP.

`evidence/account-final.sanitized.json` retains selected actual resource properties and replaces the single client IP with `REDACTED_CLIENT_IPV4`. Resource IDs, endpoints, key-creation timestamps and account identity metadata are omitted. It is a redacted resource-state excerpt, not an ARM template.

`evidence/observations.json` is an author-written transcription of the test outcomes. It is not an Azure API response or independent attestation. Original captures and their integrity manifest remain private. Public readers can inspect the sanitized results and rerun the local configuration checks; the live operations are not independently replayable from this repository alone.

`evidence/local-validation.json` is generated by executing the included Python checker against saved evidence. Its mutation checks intentionally weaken a copy of the configuration and confirm that the checker detects those changes. Neither the checker nor its report sends requests to Azure.

`sample-data/atlas-recovery-canary.txt` was prepared locally but never uploaded. Its known hash is an input hash, not proof of a successful restoration.

No screenshots, account identifiers, public client IP, access key, token, SAS, credential or personal file is included in the public repository.
